Algorithm
1. Start and initialize all variables to zero.
2. Enter the expense amount. If the input is invalid or negative, display an error message.
3. If the expense is zero, stop taking input.
4. Categorize the expense as small (less than 100), medium (100–499), or large (500 and above). Update the totals and counts.
5. Repeat Steps 2–4 until zero is entered.
6. Display the total expenses, category counts, category totals, and average expense.
7. Stop.

## Algorithm

1. Start.
2. Read the number of readings n and check that it is between 5 and 12.
3. Read all the readings and check that each value is between 0 and 1000.
4. Initialize the sum, minimum, and maximum using the readings.
5. Calculate the sum and average of all readings.
6. Find and display the minimum and maximum readings.
7. Find and display the second-largest reading, if it exists.
8. Count the local peaks in the readings.
9. Find the length of the longest increasing run.
10. Read the value of K and rotate the readings to the right by K positions.
11. Read the last two digits of the registration number and calculate D = (reg % 9) + 1).
12. Count and display the readings divisible by D, along with the value of D.
13. Stop.


Algorithm for Cinema Booking System
1. Start the program.
2. Create a 5 × 8 seating arrangement and mark all seats as available.
3. Display the menu with six options.
4. Ask the user to enter a choice.
5. If the user selects 1, display all the seats and their booking status.
6. If the user selects 2, ask for the row and seat number, check whether the seat is valid and available, then book it.
7. If the user selects 3, ask for the row and seat number, check whether it is valid and booked, then cancel the booking.
8. If the user selects 4, ask how many seats are needed together and check for consecutive available seats in a row.
9. If enough seats are available, book them; otherwise, display a message.
10. If the user selects 5, calculate and display the total booked seats, available seats and occupancy percentage.
11. If the user enters an invalid choice, display an error message.
12. Repeat the menu until the user selects 6.
13. Stop the program.

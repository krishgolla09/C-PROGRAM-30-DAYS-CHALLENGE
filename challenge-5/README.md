## Algorithm

1. Start the program.
2. Display the menu options.
3. Enter the user's choice.
4. If choice is 1, enter `a` and `b`.
5. Check and solve the linear equation.
6. If choice is 2, enter a number from 0 to 12.
7. Calculate and display the factorial.
8. If choice is 3, enter `a`, `b`, and `c`.
9. Calculate the discriminant.
10. Find and display the roots of the quadratic equation.
11. If choice is 4, display “Program completed”.
12. Repeat the menu until choice 4 is selected. If the choice is invalid, display an error message.
13. Stop the program.
